Новые Лица
Умное веб-приложение для учёта личных и совместных расходов с AI-аналитикой.
О проекте
Новые Лица — это Flask-приложение, которое помогает отслеживать личные траты, делить расходы в группах и управлять долгами. Встроенный AI-помощник анализирует расходы, автоматически категоризирует траты и отвечает на вопросы о финансах.
Возможности

    Личный учёт расходов с категориями
    Создание групп и приглашение участников по 6-значному коду
    Система долгов между участниками группы
    AI-категоризация расходов по описанию
    AI-чат для вопросов о расходах и долгах
    AI-аналитика групповых трат
    Уведомления о долгах и напоминания
    Фильтрация расходов по месяцам и категориям
    Чистый интерфейс на HTML/CSS без тяжёлых JS-фреймворков

Технологии
Backend: Python 3.8+, Flask, SQLite, OpenAI API
Frontend: HTML5, Jinja2, CSS3, Vanilla JavaScript

Использование

1)Регистрация и вход
При первом посещении нужно зарегистрироваться: указать уникальный никнейм, настоящее имя и пароль. После входа сессия сохраняется в браузере.

2)Личные расходы
На главной странице по умолчанию отображаются личные расходы. Можно добавить трату с указанием суммы, категории, описания и даты. Кнопка "Авто" использует AI для автоматического определения категории по описанию.

3)Группы
Создайте группу через кнопку "+ Создать группу" — система сгенерирует 6-значный код. Поделитесь кодом с друзьями, чтобы они присоединились через "Присоединиться". В группе видны расходы всех участников, можно отслеживать кто сколько потратил.

4)Долги
В разделе долгов можно зафиксировать кто кому должен в группе. Функция "Отправить напоминание" использует AI для генерации вежливого текста уведомления, который сохраняется в системе уведомлений должника.
AI-функции
AI-чат доступен на главной странице — можно задавать вопросы о расходах в естественной форме: "Сколько я потратил на еду в этом месяце?", "Кто больше всех тратит в группе?". AI-аналитика на отдельной странице даёт развёрнутый анализ паттернов трат.
API Endpoints
Авторизация: POST /login, POST /register, GET /logout
Группы: POST /create-group, POST /join-group
Расходы: GET / (главная с фильтрами), POST /add, POST /delete/<id>, GET /api/expenses
Долги: GET /api/debts, POST /api/add-debt, POST /api/delete-debt/<id>, GET /api/group-members/<id>
AI: POST /api/ai/ask, POST /api/ai/categorize, POST /api/ai/analyze, GET /ai-analytics
Уведомления: GET /api/notifications, GET /api/notifications/unread-count, POST /api/notifications/<id>/read, POST /api/notifications/read-all, POST /api/remind

5)База данных
Приложение использует SQLite. Таблицы: users (пользователи), groups (группы), group_members (участники), expenses (расходы), debts (долги), notifications (уведомления), categories (категории). База инициализируется автоматически через функцию init_db() при запуске.

6)Безопасность
Пароли хешируются через werkzeug.security. Сессии Flask защищены секретным ключом. SQL-запросы используют параметризацию для защиты от инъекций.
